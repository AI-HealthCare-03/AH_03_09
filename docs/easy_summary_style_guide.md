# Easy Summary Style Guide

## 목적

복약 가이드를 환자가 집에서 쉽게 이해하고 안전하게 복용할 수 있도록 설명한다.

---

# 기본 원칙

## 1. 환자 행동 중심으로 작성

* 환자가 실제로 해야 하는 행동을 우선 설명한다.
* 복약 방법과 주의사항을 짧고 명확하게 전달한다.
* 설명보다 실제 복약 행동 안내를 우선한다.

예:

* 하루 한 번 복용하세요.
* 식사와 관계없이 복용할 수 있습니다.
* 복용 중 이상 증상이 있으면 의료진과 상담하세요.

---

## 2. 의사용 표현 최소화

다음 표현은 피한다.

* 치료 전환
* 초기 용량 조절
* 임상시험 결과
* 허가/승인 문체
* 처방 결정 표현
* 연구/통계 설명

사용 금지 예시:

* "이 약으로 전환할 수 있습니다."
* "초기 용량 조절이 필요합니다."
* "임상시험 결과 유의한 차이를 보였습니다."

가능하면 다음과 같이 환자 친화 표현으로 변환한다.

| 비권장 표현 | 권장 표현         |
| ------ | ------------- |
| 투여     | 복용            |
| 병용요법   | 함께 복용         |
| 용량 조절  | 의료진 안내에 따라 복용 |
| 투여 간격  | 복용 간격         |

---

## 3. 이미 처방받은 환자 기준으로 작성

현재 사용자는 이미 진료 후 약을 처방받은 상태라고 가정한다.

따라서:

* "복용 전 상담하세요" 반복 사용 최소화
* 처방 여부를 다시 결정하는 표현 금지
* 용량 변경을 환자가 스스로 결정하는 것처럼 작성 금지

대신:

* 복용 중 주의사항
* 이상 반응 관찰
* 실제 복약 행동
  중심으로 설명한다.

---

## 4. 환자가 임의로 결정하는 느낌의 문장 금지

다음과 같은 표현은 피한다.

* "증상이 지속되면 4주 더 복용할 수 있습니다."
* "용량을 조절할 수 있습니다."
* "병용요법을 시행합니다."

대신 다음과 같이 표현한다.

* "처방받은 기간과 방법을 지켜 복용하세요."
* "의료진의 안내에 따라 복용하세요."
* "복용 중 이상 증상이 있으면 의료진과 상담하세요."

---

## 5. 성분명 중심 설명 최소화

환자 복약 행동에 필수적이지 않은 경우 성분명 중심 설명을 직접 노출하지 않는다.

특히 다음과 같은 표현은 가능한 환자 행동 중심 문장으로 변환한다.

예:

* "아세트아미노펜 최대 4000mg 초과 금지"
  → "다른 해열진통제와 함께 복용하지 않도록 주의하세요."

* "중복 성분 복용 주의"
  → "비슷한 효능의 약을 함께 복용하지 않도록 주의하세요."

---

## 6. 과도한 위험 강조 표현 완화

환자에게 불필요한 공포를 줄 수 있는 표현은 가능한 부드럽고 직접적인 행동 문장으로 변환한다.

예:

* "태아에 손상을 줄 수 있습니다."
  → "임신 중에는 복용하지 마세요."

* "심각한 이상반응이 발생할 수 있습니다."
  → "이상 증상이 나타나면 의료진과 상담하세요."

---

# 우선 포함 정보

다음 정보를 우선적으로 포함한다.

1. 복용 횟수
2. 복용 방법
3. 식사 관계
4. 임신/수유 주의
5. 간·신장 질환 주의
6. 어린이 사용 주의
7. 보관 방법
8. 중대한 이상 반응

---

# 문장 스타일

## 권장 스타일

* 짧고 단순한 문장
* 환자 행동 중심
* 쉬운 한국어 사용
* "하세요" 형태 우선 사용

예:

* 하루 한 번 복용하세요.
* 식사와 관계없이 복용할 수 있습니다.
* 어린이의 손이 닿지 않는 곳에 보관하세요.

---

## 비권장 스타일

* 긴 의학 문장
* 표 설명
* 허가사항 원문 복붙
* 임상시험 데이터 설명
* 과도한 전문용어

---

# 데이터 소스별 원칙

## e약은요 데이터

* 기존 easy_summary 스타일 유지
* 지나치게 의학적인 표현은 완화
* 과도한 상담 문구 반복은 최소화
* 원래 환자 친화 문체는 유지한다.

## 제품허가정보 fallback

* 허가문 원문을 그대로 노출하지 않는다.
* 환자 행동 중심으로 재구성한다.
* 전문의약품도 일반 환자가 이해 가능한 수준으로 표현한다.
* HTML, 표 데이터, 임상시험 원문은 직접 노출하지 않는다.
* 허가문 설명보다 실제 복약 행동을 우선한다.

# 금지 문구 예시

다음 표현은 easy_summary에서 제거하거나 사용하지 않는다.

* 전환할 수 있습니다
* 초기 용량
* 임상시험
* 복용 전 의료진
* 복용 전 상담

---

# 목표 UX

사용자가 5문장 이내로 아래 내용을 빠르게 이해할 수 있어야 한다.

* 언제 먹는지
* 어떻게 먹는지
* 무엇을 조심해야 하는지
* 어떤 상황에서 주의해야 하는지
* 이상 증상이 생기면 어떻게 해야 하는지

---

# 향후 개선 방향

* 약물군별 맞춤 복약 가이드
* 제형별 안내 분리
* 환자 연령별 설명 조정
* 챗봇/RAG 연계 컨텍스트 활용
* 핵심 주의사항 자동 추출 고도화
